Guide Coffre

Installation et utilisation
Télécharger Guide pas à pas Code source

Ce guide explique étape par étape comment installer Coffre, créer votre coffre et remplir vos identifiants. Les visuels ci-dessous reproduisent l’interface réelle de l’application.

Windows — Installation

Étape 1 — Téléchargement
Coffre-Setup-Windows.exe36 Mo · Installateur
  1. Téléchargez l’installateur depuis la page d’accueil.
  2. Double-cliquez le fichier dans Téléchargements.
  3. Cliquez Installer (pas d’admin requis).
Étape 2 — Mot de passe maître

Minimum 12 caractères

  1. Au premier lancement, créez un mot de passe maître.
  2. Confirmez-le. Notez-le dans un endroit sûr.
  3. S’il est oublié, les données sont irrécupérables (volontaire).
Étape 3 — Accueil Coffre
Gmailedouard@… · Gmail
Steammonpseudo · Steam
Discorduser@… · Discord
  1. La liste affiche vos comptes triés par ordre alphabétique.
  2. Utilisez la barre de recherche pour filtrer.
  3. Touchez + Ajouter pour créer une entrée (titre, identifiant, mot de passe, site).

Android — Installation

Étape 1 — Installer l’APK
Coffre.apkOuvrir avec le gestionnaire de fichiers
  1. Téléchargez Coffre.apk sur le téléphone.
  2. Ouvrez-le et autorisez l’installation si Android le demande.
  3. Créez le mot de passe maître (12 caractères min.).
Étape 2 — Remplissage automatique
Activer le remplissage automatiqueParamètres Coffre
Service : CoffreSélectionné
  1. Ouvrez Paramètres dans Coffre.
  2. Activez le remplissage automatique.
  3. Dans les réglages Android, choisissez Coffre comme service de saisie.
Étape 3 — Connexion dans une app
Suggestion Coffremoncompte@gmail.com
  1. Ouvrez Chrome ou une application.
  2. Touchez le champ identifiant : une suggestion Coffre apparaît.
  3. Un tap remplit identifiant et mot de passe (coffre déverrouillé).

Utilisation au quotidien

Copier identifiant + mot de passe

  • Windows : touchez une ligne → Utiliser. L’identifiant est copié, puis le mot de passe après votre Ctrl+V.
  • Windows accès rapide : Ctrl+Shift+Espace dans n’importe quelle app (Coffre déverrouillé).
  • Android : icône éclair → recherche → Utiliser, ou suggestion clavier.
  • Le presse-papier s’efface automatiquement après ~30 secondes.

Navigateur (Windows)

  • Installez l’extension Coffre (dossier extension/ du dépôt).
  • Coffre ouvert et déverrouillé.
  • Cliquez un champ e-mail : menu Comptes Coffre (liste triée A→Z).
  • Paramètres Coffre → Désactiver Google Password Manager si les deux se chevauchent.

Mises à jour

  • Coffre vérifie GitHub à l’ouverture.
  • Un bandeau propose d’installer la nouvelle version.
  • Installez par-dessus : le coffre chiffré n’est pas touché.
