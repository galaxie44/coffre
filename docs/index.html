Disponible

Coffre pour Windows

Double-cliquez l’installateur. Aucun droit administrateur requis.

Télécharger Coffre-Setup-Windows.exe Inclut le programme « Tout supprimer »
1

Téléchargez

Cliquez le bouton ci-dessus ou ouvrez la page Releases.

2

Installez

Lancez l’installateur → Suivant → Installer. Raccourci Bureau + menu Démarrer.

3

Créez le mot de passe maître

12 caractères minimum. S’il est perdu, le coffre est irrécupérable.

4

Utilisez Coffre

Ajoutez vos comptes, Ctrl+Shift+Espace pour l’accès rapide, extension Chrome pour le web.

Disponible

Coffre pour Android

Copiez l’APK sur le téléphone et ouvrez-le.

Télécharger Coffre.apk Autorisez « sources inconnues » si Android le demande
1

Téléchargez l’APK

Sur le téléphone ou transférez-le depuis un PC.

2

Installez

Ouvrez le fichier → Installer. Confirmez si Android affiche un avertissement.

3

Activez le remplissage auto

Coffre → Paramètres → Activer le remplissage automatique → choisissez Coffre.

4

Connectez-vous

Touchez un champ identifiant dans Chrome ou une app : suggestion Coffre au-dessus du clavier.

Nouveau

Coffre pour macOS

Version bureau pour Mac (Apple Silicon et Intel). Téléchargement disponible dès la prochaine release GitHub.

Télécharger Coffre-macOS.zip Si absent : la build arrive avec la prochaine mise à jour
1

Téléchargez le .zip

Décompressez pour obtenir Coffre.app.

2

Première ouverture

Clic droit → Ouvrir (macOS bloque les apps non signées au premier lancement).

3

Glissez dans Applications

Optionnel : placez Coffre.app dans le dossier Applications.

4

Créez votre coffre

Même principe que Windows : mot de passe maître local, liste de comptes chiffrée.

Nouveau

Coffre pour Linux

Archive prête à l’emploi pour distributions x64 (Ubuntu, Debian, Fedora…).

Télécharger Coffre-Linux-x64.tar.gz Si absent : la build arrive avec la prochaine mise à jour
1

Extrayez l’archive

tar -xzf Coffre-Linux-x64.tar.gz puis entrez dans le dossier coffre.

2

Lancez

./coffre — installez les dépendances GTK si demandé par votre distro.

3

Créez le mot de passe maître

Le coffre est stocké dans votre dossier utilisateur, chiffré localement.

4

Raccourci (optionnel)

Créez un lanceur .desktop pointant vers le binaire coffre.

Mettre à jour

À partir de la 1.0.1, Coffre propose les mises à jour à l’ouverture (Windows & Android). Installez par-dessus sans désinstaller — sinon le coffre local serait perdu.

Besoin d’aide ?

Consultez le guide pas à pas avec captures ou le bouton Aide dans l’application (accueil ou Paramètres).
